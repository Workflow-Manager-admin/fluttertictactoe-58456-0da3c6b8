# Tic Tac Toe Flutter App

A simple, minimalistic Player vs Player Tic Tac Toe mobile game built with Flutter.

## Features

- Player vs Player mode
- Responsive design
- Centralized 3x3 game board with smooth animations
- Light, clean, minimal UI
- Score tracking (local for X, O, and draws)
- Win/draw/tie detection
- Game restart/reset and clear scores controls
- Themed colors:
    - **Primary:** #1976D2 (blue)
    - **Secondary:** #43A047 (green)
    - **Accent:** #FFC107 (amber/yellow)

## How to Play

- Tap on any empty cell to make your move.
- First player is X, then O, turns alternate.
- The winner or a draw is announced automatically.
- Tap "Restart" to play a new round, or "Clear Scores" to reset all scores.

## Project Structure

- `lib/main.dart`: Main app logic, UI, and game management.
- No external dependencies required.
